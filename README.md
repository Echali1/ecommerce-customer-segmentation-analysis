## Project Overview

This project analyzes an e-commerce dataset containing more than **540,000 transactions** to understand customer behavior and sales performance.

The objective is to extract **business insights** and identify **high-value customers** using data analysis and customer segmentation techniques.

---

## Dataset

Online retail dataset including:

- transactions
- customers
- products
- order dates
- sales amounts

Total transactions analyzed: **540k+**

---

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Power BI

---

## Analysis Performed

### Data Cleaning
- handling missing values
- removing duplicates
- formatting dates

### Exploratory Data Analysis
- sales trends
- top-selling products
- revenue distribution

### Customer Segmentation

Implemented:

- **RFM Segmentation**
- **Cohort Analysis**
- **Pareto Analysis (80/20)**

to identify high-value customers and analyze customer retention.

---

## Key Insights

- Top **20% of customers generate ~80% of revenue**
- Clear seasonality in sales trends
- High-value customers identified using RFM segmentation

---

## Dashboard

An interactive **Power BI dashboard** was created to visualize:

- revenue trends
- sales by product
- customer segmentation
- key business KPIs
